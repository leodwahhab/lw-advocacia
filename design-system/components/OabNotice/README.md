# OabNotice

Linha discreta que informa o caráter informativo da página, conforme o Provimento 205/2021.

**Anatomia.** `p.oab-notice`, um parágrafo só.

**Tokens.** `--text-caption` (13px), `--color-text-muted` no claro (6,5:1) e `--color-text-inverse-muted` no marinho (7,1:1).

**Uso.** Fica na faixa inferior do rodapé. Discreto não quer dizer ilegível: nunca abaixo de 13px nem com contraste menor que 4,5:1. Largura máxima de 80ch. O texto final deve ser revisado pelo(a) advogado(a) responsável.

**Estados.** Estático.
